Module 2

JAVA Programming

1. DAY 01 : Introduction to Programming & Java Basics

  • Learn what programming is and get introduced to Java - its features, how it works via the JVM, and the structure of a basic Java program.
  • Java Features : High-level , Object-oriented, Secure, Reliable, Platform-independent
  • Java Uses: Android/Mobile Apps, Web Backends, Enterprise Systems, Desktop Applications
  • Key Concepts: WORA ,JDK, JVM, class, main(), static, void, String[] args, print() vs println()

2. DAY 02 : Variables, Data Types & Operators

  • Learn how to store data using variables, take user input with Scanner, and perform operations using Java's operators.
  • Data Types : int, float, double, char, boolean ,String
  • Scanner Methods: nextInt(), nextDouble(), nextFloat(), next(), nextLine(), nextBoolean()
  • Operators : Arithmetic, Relational, Logical, Increment/Decrement

3. DAY 03 : Operators & Conditional Statements

  • Go deeper into all types of Java operators and learn how a program can make decisions using conditional statements
  • Types of Operators : Arithmetic (+ - * / %), Relational (== != > < >= <=), Logical (&& || !), Assignment (= += -= *= /= %=), Unary (++ -- + - ! ~), Bitwise (& | ^ ~), Shift (<< >> >>>), Ternary (? :)
  • Conditional Statements: if, if-else, if-else-if ladder, Nested if, switch

4. DAY 04 : OOP Basics: Class, Object & Constructor

  • Get introduced to Object-Oriented Programming in Java through its core building blocks - class, attributes, methods, objects and constructors.
  • OOP Building Blocks: Class, Attributes, Method, Object, Constructor

5. DAY 05 : The Four Pillars of OOP

  • Learn the four core pillars of Object-Oriented Programming - Encapsulation, Inheritance, Polymorphism and Abstraction - with real-world examples.
  • Encapsulation: private, public, Getters, Setters
  • Inheritance : extends keyword, super keyword,, Code Reusability, Single Inheritance Only
  • Polymorphism : Method Overloading (compile-time), Method Overriding (runtime)
  • Abstraction : abstract keyword, interface, implements, Abstract Class, Interface
