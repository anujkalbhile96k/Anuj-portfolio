Module 7

Networking

1. DAY 01 : Data Communication

  • Understand the basics of data communication - how information is exchanged between devices, its core components and key characteristics.
  • Core Components: Sender, Receiver, Message,, Transmission Medium, Protocol
  • Characteristics: Delivery, Accuracy, Timeliness, Jitter

2. DAY 02 : Computer Networks

  • Learn what a computer network is, why networking matters, and the different types of networks based on their coverage area.
  • Why Networking? : Resource Sharing, Data Sharing, Communication, Cost Reduction, Centralized Management
  • Types by Coverage: PAN, LAN, MAN, WAN

3. DAY 03 : Topologies & Networking Devices

  • Explore the different physical/logical layouts used to arrange a network and the hardware devices that make networking possible.
  • Network Topologies: Bus, Star, Ring, Mesh, Hybrid
  • Networking Devices : Hub, Switch, Router

4. DAY 04 : OSI Model & Protocols

  • Understand the OSI model - the conceptual framework used to describe how data travels through a network - and get introduced to networking protocols.
  • OSI Layers: Physical, Data Link, Network, Transport, Session, Presentation, Application
  • Protocols: Set of Rules, Ensures Compatibility, Enables Communication

5. DAY 05 : HTTP, IP, DHCP & DNS

  • Learn how the web communicates using HTTP, how devices are identified with IP addresses, and how DHCP and DNS automate networking.
  • HTTP Methods: GET, POST, PUT, DELETE
  • IP Addressing: IPv4, IPv6
  • Key Services: DHCP, DNS

6. DAY 06 : ARP, ICMP & Revision

  • Learn about two key network-layer protocols and revise the topics covered so far in the module.
  • Protocols: ARP, ICMP

7. DAY 07 : WebSocket & Project Discussion

  • Learn how real-time, two-way communication works on the web using WebSocket and WebRTC, and discuss project ideas to apply networking concepts.
  • Real-time Communication: WebSocket, WebRTC (Web Real-Time Communication)
  • Wrap-up: Project Ideas , Project Discussion
