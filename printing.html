Module 2

Computer Aided Designing

1. DAY 01 : Sketching Basics

  • Learnt the basics of 2D sketching in CAD - selecting planes and views, and using various sketch tools that form the foundation of every 3D model.
  • Sketch Tools : Line, Midpoint Line, Circle, Arc, Rectangle, Polygon , Spline, Slot , Ellipse, Mirror, Circular Pattern, Rectangular Pattern, Text
  • Modify Tools : Fillet, Chamfer, Offset, Trim, Break, Extend
  • Constraints : Horizontal/Vertical, Coincident, Equal, Parallel, Perpendicular, Collinear, Cocentric

2. DAY 02 : Sketch Practice

  • Practiced the sketching tools learnt on Day 1 to build speed and accuracy before moving to 3D modeling.
  • Focused entirely on practicing sketches to strengthen fundamentals before moving on to 3D features like extrusion

3. DAY 03 : Extruding

  • Learnt how to convert 2D sketches into 3D solid bodies using the Extrude feature, along with creating and grounding components.
  • Extrude - Start : Profile (selects whole plane), Offset (creates a similar body), Object (extrudes from a surface)
  • Extrude - Operation : Join, Cut, Intersect, New Body, New Component
  • The Modify section in 3D works similarly to sketching. Also learnt how to create a component and how to ground/unground it.

4. DAY 04 : Assembly, Fasteners & Embossing

  • Learnt how to assemble multiple components with motion, model nuts and bolts, and emboss text onto a surface.
  • Assembling : Join (J command), Position, Motion, Fix Component
  • Fasteners : Bolt - External Threading, Nut - Internal Threading, Standard Units

5. DAY 05 : Assembly & Motion

  • Went deeper into assemblies - understanding the difference between components and bodies, and adding real-world motion using joints.
  • Concepts: Components vs Bodies, Joint Tool, Motion Study
  • Practice: created a simple hinge mechanism to apply the Joint tool and Motion study concepts.

6. DAY 06 : Engineering Practice

  • Modeled real engineering parts and learnt tools to measure and inspect a design for accuracy.
  • Parts Created: Spur Gear (basic), Plate with Holes
  • Tools Learnt: Measure Tool, Inspect
